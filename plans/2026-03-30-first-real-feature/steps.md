# Step Decomposition

1. Fill the task plan for the new feature before broad edits.
2. Add shared task-plan analysis in `src/lib/`.
3. Add the `plans:list` CLI command and package script.
4. Add tests for ready and incomplete task plans.
5. Update the starter docs with the new command.
6. Run format, docs stamp, validate, and record the results.

## Scope Change Rule

If new files become necessary outside the command, shared task-plan analysis, tests, docs, or this plan folder, record the reason here before widening the scope.
