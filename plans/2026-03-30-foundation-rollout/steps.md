# Step Decomposition

1. Add the missing repo scaffolding for memory, prompts, plans, and docs.
2. Add reusable plan creation and publish commands.
3. Update health checks and tests so the repo can verify its own workflow.
4. Exercise the workflow on itself with real task plans and dry-run publishing.
5. Run format, docs stamp, validate, and repo health.
6. Publish the whole rollout from an umbrella task plan as a draft PR.

## Scope Change Rule

If more changes become necessary outside the documented scaffold, record the reason here before widening the scope beyond repo-workflow infrastructure.
